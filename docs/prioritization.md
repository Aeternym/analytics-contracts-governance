# Prioritization

Recommended backlog order:

1. P0 governance: Git baseline, ownership model, lifecycle transitions and privacy-safe owner representation.
2. P0 format: one required field set for each contract type and synchronized templates.
3. P0 pilot: review a small group of business-critical metrics with accountable owners.
4. P1 relationships: domains, reusable dimensions, segments, dashboards and consumers.
5. P1 automation: validate structure, IDs, references and lifecycle gates in CI.
6. P2 publication: generate a read-only documentation view from an approved Git commit.

Priority labels must be defined by governance rather than inferred from file names.
